# WorldWar Bot — Frontend Demo

<div dir="rtl">

نمایش رابط کاربری (UI) وب‌سایت اشتراک بازی «جنگ جهانی» — **فقط فرانت‌اند**، بدون سرور، دیتابیس، درگاه پرداخت واقعی یا ربات تلگرام.

این پروژه فقط برای نمایش طراحی و تجربه‌ی کاربری ساخته شده. دکمه‌ی «پرداخت» صرفاً یک شبیه‌سازی نمایشی است (بدون تراکنش واقعی) و اطلاعات داشبورد (پلان، آمار، تاریخچه‌ی پرداخت) نمونه‌سازی‌شده و ثابت هستند.

## 🚀 اجرا روی کامپیوتر خودت

```bash
git clone <repository-url>
cd worldwar-frontend-demo
npm install
npm start
```

سایت روی آدرس `http://localhost:3000` باز می‌شود.

## 🌐 انتشار روی GitHub Pages

```bash
npm install
npm run deploy
```

این دستور پروژه را build کرده و مستقیم روی شاخه‌ی `gh-pages` همین ریپو منتشر می‌کند. بعد از اجرا، از تنظیمات ریپو (Settings → Pages) شاخه‌ی `gh-pages` را به‌عنوان source انتخاب کن.

> نکته: اگر ریپو زیرمسیر داره (مثلاً `username.github.io/repo-name`)، فیلد `homepage` توی `package.json` رو مطابق آدرس واقعی ریپو تنظیم کن.

## 📁 ساختار

- `src/App.jsx` — کل رابط کاربری (صفحه‌ی اصلی، ویژگی‌ها، قیمت‌گذاری، داشبورد نمایشی)
- `public/` — فایل HTML پایه

## ⚠️ محدودیت‌ها

این نسخه بک‌اند واقعی ندارد؛ یعنی:
- پرداخت واقعی انجام نمی‌شود
- اطلاعات کاربر ذخیره نمی‌شود
- به ربات تلگرام متصل نیست
